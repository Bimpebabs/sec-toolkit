# Section Definitions

Scope and boundaries for each top-level section in the sec-toolkit README.

## 1. Reconnaissance & OSINT

Tools for gathering information about a target before active engagement. Includes subdomain enumeration, port scanning, search engines, Git/code recon, and OSINT frameworks.

**Not here:** Tools that send active exploit traffic (those go in Web Application Security or Exploitation).

## 2. Web Application Security

Tools for testing web applications and APIs. Includes scanners, fuzzers, injection testing, and API testing tools.

**Not here:** Network-level scanners (those go in Network & Infrastructure).

## 3. Network & Infrastructure

Tools for network-level assessment: port scanners, vulnerability scanners, wireless tools, and database assessment.

**Not here:** Web-specific tools (those go in Web Application Security).

## 4. Identity & Access

Tools for attacking or assessing identity systems: Active Directory, Kerberos, password attacks, and credential manipulation.

**Not here:** General network tools (those go in Network & Infrastructure).

## 5. Exploitation & Post-Exploitation

Tools for gaining and maintaining access: exploitation frameworks, C2 frameworks, privilege escalation, and tunneling.

**Not here:** Recon tools (those go in Reconnaissance).

## 6. Container & Kubernetes Security

Tools for container and Kubernetes security assessment, posture management, and runtime protection.

## 7. AI / LLM Security

Tools for assessing the security of AI/LLM applications: scanners, red-teaming frameworks, guardrails, and model analysis tools.

## 8. Cloud Security Posture

Tools for assessing cloud configurations: multi-cloud posture auditing, IAM analysis, and governance.

## 9. Supply Chain Security

Tools for assessing software supply chains: SBOM generation, vulnerability scanning, signing, and provenance.

## 10. Detection Engineering & DFIR

Tools for detection, forensics, and incident response: detection rules, SIEM, endpoint monitoring, and forensic analysis.

## 11. Reporting & Collaboration

Tools for documenting and collaborating on security work: report generators, engagement management, and team platforms.

## 12. Distributions & Cyber Ranges

Tools for practicing security: penetration testing distributions, practice labs, and cyber ranges.
